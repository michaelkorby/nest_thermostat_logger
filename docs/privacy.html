Privacy Policy

Nest Temperature Logger - last updated November 20, 2026

Who uses this app

Nest Temperature Logger is a personal tool used only by its developer, with the developer's own Google account and Nest devices. It is not offered to other users.

What data it accesses

  • Nest thermostat data through the Google Smart Device Management API (scope https://www.googleapis.com/auth/sdm.service): device names, indoor temperature, humidity, temperature setpoints and HVAC status.
  • Google Drive (if enabled, scope https://www.googleapis.com/auth/drive.file): only the files this app itself creates, which hold the thermostat logs. It cannot see any other Drive files.
  • Outdoor temperature from the public U.S. National Weather Service API, which involves no personal data.

How the data is used and stored

The data is used only to record and chart the developer's own home temperature history. It is stored on the developer's own computer and in the developer's own Google Drive. OAuth tokens are stored only on that computer.

Sharing

Data is not sold, shared, or transferred to anyone, and is not used for advertising or any purpose other than the logging described above.

Nest Temperature Logger's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions or in the Google Home app. Logged data can be deleted by deleting the CSV files.

Contact
